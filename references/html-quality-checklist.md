# 本地 HTML 质量检查清单

## 结构

- [ ] 正确的 DOCTYPE
- [ ] `<html>` 有 `lang`
- [ ] 有描述性的 `<title>`
- [ ] 有 viewport meta
- [ ] 有唯一 `<main>`
- [ ] 有唯一主 `<h1>`
- [ ] 标题层级合理
- [ ] 导航标签有意义

## 内容

- [ ] 产品名称可见且拼写一致
- [ ] 主 CTA 清楚并合理重复
- [ ] 声明有来源或标记待确认
- [ ] 没有把占位文案当作最终内容
- [ ] 没有虚构奖项、评价、指标或认证
- [ ] 法律和商标文案由用户提供或标记待确认

## 转化

- [ ] CTA 目标明确
- [ ] 邮件表单有 label、Consent 和集成说明
- [ ] Cookie 可选类别与必要类别分开
- [ ] 授权前不加载可选脚本
- [ ] 移动 CTA 不遮挡 Cookie 控件

## 视觉

- [ ] Hero 没有遮挡产品
- [ ] 遮罩在当前图片上足够清晰
- [ ] 产品图没有被无意裁切
- [ ] Logo 没有被放大到模糊
- [ ] 奖项/证书完整可见
- [ ] 首屏文字层级清楚
- [ ] 页面不像未完成的通用模板

## 响应式

- [ ] 390px 手机
- [ ] 768px 平板
- [ ] 1280px 桌面
- [ ] 1440px 宽屏
- [ ] 没有横向溢出
- [ ] 吸顶导航可用
- [ ] 页脚在移动端堆叠合理
- [ ] 参数表在小屏可读

## 可访问性

- [ ] 焦点状态可见
- [ ] 图片 alt 合理
- [ ] 表单错误可被读屏感知
- [ ] 支持 reduced-motion
- [ ] 不依赖颜色传达唯一信息

## 交付

- [ ] `REVIEW.md` 列出未完成内容和生产集成
- [ ] 没有部署说明
- [ ] 没有密钥和私密数据
- [ ] 最终 HTML 本地打开无坏图
- [ ] `node scripts/validate-html.mjs index.html` 通过
